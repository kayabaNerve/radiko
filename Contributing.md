# Contributing

All contributions to Radiko are done with pull requests. This project has a
series of established regulations regarding contributed code, as follows:

1) All code contributed must be your own work as an individual, or legally
   licensed and appropriately attributed.

2) All contributions must be source, without any binaries, and asserted as such
   upon submission.

3) The priorities of the code are safety first and foremost, propriety second,
   and clarity third.
